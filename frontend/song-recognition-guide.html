听音识曲：从注册到配置密钥

核对日期：2026-09-13。用于中国大陆 ACRCloud 翻奏识别。网站界面、试用额度与价格可能变化，以你自己的控制台为准。

不需要编程，也不必为了试用绑定支付方式。请使用自己的账号和密钥；不要把 Secret Key 发给别人、贴进聊天或公开截图。

1. 注册账号并完成邮箱验证

打开中国站：https://console.acrcloud.cn/，选择“注册 / Signup”。填写能收邮件的邮箱、用户名和密码，按页面提示完成注册，再打开验证邮件中的链接。

如果页面出现“公司”栏，可以随便写一个用途名称，例如“个人学习”；不需要为了使用补丁注册公司。此项是填写建议，不代表可绕过网站的实际校验或条款。若没有这一栏，直接跳过。

2. 进入音频识别服务，选择中国区域

登录后，在“产品与服务”中打开“音频指纹识别 / Audio & Video Recognition”，选择 China / cn-north-1。这里的产品名称虽然叫“音频指纹识别”，创建项目时仍可选择“翻奏识别”引擎。不要选“文件扫描”或“离线识别”。

打开中国区域控制台，点击“音频指纹识别项目”进入项目列表。

3. 创建翻奏识别项目

在项目列表点击“创建项目”，按照下图选择：

  • 项目名称：自己起名，例如“本地演奏识曲”。
  • 音频类型：原始文件或流媒体（未包含噪音）。
  • Audio Engine：Cover Song (Humming) Identification。只选 Audio Fingerprinting 主要匹配原版录音，不适合游戏定制演奏。
  • 资源库：ACRCloud Music。
  • 第三方 ID（Spotify、YouTube 等）：只需要歌名，可以不选。

确认配置后点击“Confirm / 确认”。试用账号通常只能创建一个 AVR 项目；如果已有项目，先检查它的配置，不要反复新建。

4. 找到自己的 Access Key 与 Secret Key

创建完成后，返回项目列表。同一项目所在行会显示 Host、Access Key、Secret Key。复制自己的两个 Key；不要复制教程图片中的示例，也不要使用 Console API Token 代替项目密钥。

你的 Host 应为 identify-cn-north-1.acrcloud.cn。补丁当前固定使用中国区域；若 Host 不一致，请回到中国区域检查项目。

5. 回游戏保存设置，再开始识别

打开游戏“设置”，在“本地回信”前找到“听音识曲”。分别粘贴两个 Key，再点“保存识曲设置”。“请求额度”默认折叠，单次和每日上限均默认5000；需要调整时再展开。旁边的问号可悬浮或键盘聚焦查看免费试用说明。开始识别时会发送匿名短音频，可能消耗额度或产生费用。看到“已配置识曲服务”即表示密钥已保存，不代表已经验证额度或识别服务可用。

随后打开“我的上传 → 管理本地演奏 → 歌曲管理”，点击“立即识别”。每首会按需采样，最多5段。你也可以在“识别设置”开启自动识别，以及分别设置高、中、低可信度是否自动暂用；默认高、中开启，低关闭。自动暂用不等于手动确认。

免费试用、限制与额度不足

官方说明注册后提供 14天免费试用，不是永久免费。2026-09-13检查的中国站试用控制台显示：每天5000次识别请求、QPS 2、最多1个AVR项目。这些是当时账号的限制，不保证每个新账号相同；请查看自己控制台的“限制”和试用剩余时间。

额度按请求计，不按歌曲计。每首2—5段时，30首大约需要60—150次请求；匹配较弱、重试等情况会多消耗请求，不能把5000次理解为5000首。本地预算不是服务商余额查询，服务商计费结果为准。

  • 请求额度超限（3003）：停止发送新请求，任务暂停并保留已保存结果。检查试用期限、每日配额或套餐后，手动点击“继续”；不会自动重试或自动充值。
  • 每秒请求过多（3015 / HTTP 429）：暂停任务。等其他设备或程序的并发请求减少后手动继续。
  • 本地预算用完：暂停；本次预算需要明确追加后才能继续，每日预算达到后也不会绕过。
  • 没有匹配结果（1001）：这是识别结果，不是额度不足；按本次采样上限继续尝试，完成后保留记录，不自动重跑。

试用到期、余额不足或其他服务错误，不一定都有单独错误码。无法确定原因时显示服务异常并保留安全错误码，请在控制台核对，不会把它伪装成“没有匹配”。

查看中国站价格与套餐 · 官方错误码说明。本补丁不会替你购买或升级。
